# meta-asm-tool
Metagenome assembly tools

## tools
| tool | time | sequencing type | where | description |
|--------|--------|--------| --------| --------|
| strainy  | 2024  | long - Nanopore or PacBio HiFi  | https://github.com/katerinakazantseva/strainy | takes an initial de novo metagenomic assembly as input and expands the assembly by reconstructing strain haplotypes |
| strainberry | 2021 | long | https://github.com/rvicedomini/strainberry | input assembly |
| hifiasm-meta | 2022 | hifi | https://github.com/xfengnefx/hifiasm-meta | denovo |
| metaFlye |
| metaMDBG |
| Ragout | 2014/2018 | short - configs | https://github.com/mikolmogorov/Ragout | Given initial assembly fragments (contigs/scaffolds) and one or multiple related references (complete or draft), it produces a chromosome-scale assembly (as a set of scaffolds). The approach is based on the analysis of genome rearrangements (like inversions or chromosomal translocations) between the input genomes and reconstructing the most parsimonious structure of the target genome. |
| Multi-CSAR | 2018 | short - configs | https://github.com/ablab-nthu/Multi-CSAR | Multi-CSAR is a scaffolding tool that can order and orient the contigs of a target draft genome based on multiple complete and/or incomplete reference genomes of related organisms. |
| Pasa | 2024 | short - configs | https://github.com/amromics/pasa | Pasa builds the former graph by using PanTA on a large set of genomes and using it as the guide to resolve the assembly graphs generated by SPAdes assembler |
| gramtools | 2021 | short | https://github.com/iqbal-lab-org/gramtools | gramtools builds a genome graph from a reference genome and a set of variants (VCF files or MSAs files). Given sequence data from an individual, the graph is annotated with coverage and genotyped, producing a VCF file, and a jVCF file, of all the variation in the graph. A personalised reference genome for the sample is also inferred and new variation can be discovered against it. You can then build a new graph from the initial and the new variants, and genotype this augmented graph. |
